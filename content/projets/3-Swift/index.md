# Swift

Swift est un langage de développement originalement développé par Apple pour le développement d'applications sur MacOS et IOS. Ce langage est fortement typé avec un système d'inférence de type *à la* Haskell.

J'ai pu documenter mes expériences de développement par quelques documents;

### Regular expressions in Swift

Swift a toujours permis l'utilisation d'expression régulières, mais c'était via un pont avec une base Objective-C qui nécessitait ceraines conversions souvent complexes. Swift 5.7 a introduit le type `Regex` avec plusieurs originalités que j'ai expliquées et fait ressortir dans un document (en anglais).
